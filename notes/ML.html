جزوه آموزشی هوش مصنوعی

موضوع: مبانی Machine Learning و Deep Learning

هدف این جزوه، مرور مفهومی مباحث پایه یادگیری ماشین و یادگیری عمیق است. سعی شده رابطه میان مفاهیم به‌صورت منسجم بیان شود تا خواننده علاوه بر آشنایی با تعاریف، بتواند ارتباط آن‌ها با یکدیگر را نیز درک کند.

1. Machine Learning چیست؟

Machine Learning شاخه‌ای از هوش مصنوعی است که در آن به‌جای تعریف دستی تمام قوانین تصمیم‌گیری، به مدل داده می‌دهیم تا الگوهای موجود در داده را یاد بگیرد و سپس برای داده‌های جدید پیش‌بینی یا تصمیم‌گیری کند.

Data → Learning Algorithm → Model → Prediction

برای مثال، در مسئله تشخیص سبک نقاشی، به‌جای نوشتن قوانین دستی برای تشخیص سبک Van Gogh یا Picasso، تصاویر برچسب‌دار به مدل داده می‌شود تا ویژگی‌های مرتبط با هر سبک را خودش یاد بگیرد.

تعریف به زبان انگلیسی: Machine Learning is a field where models learn patterns from data and use those learned patterns to make predictions or decisions instead of relying entirely on explicitly programmed rules.

2. Supervised و Unsupervised Learning چه تفاوتی دارند؟

Supervised Learning

داده‌ها دارای Label هستند و مدل یاد می‌گیرد ورودی را به خروجی مورد انتظار مرتبط کند.

Image → Label
Painting → Van Gogh
Painting → Picasso

Unsupervised Learning

داده‌ها Label ندارند و مدل تلاش می‌کند ساختار یا الگوهای موجود در داده را خودش پیدا کند؛ مانند Clustering.

Unlabeled Data → Model → Discovered Groups / Patterns

مثال کاربردی:

مسئله تشخیص سبک نقاشی، در صورتی‌که تصاویر دارای Label باشند، نمونه‌ای از یک مسئله Supervised Learning است.

تعریف به زبان انگلیسی: In supervised learning, the model learns from labeled data, while in unsupervised learning, the model tries to discover patterns or structures in unlabeled data.

3. Classification و Regression

هر دو معمولاً از مسائل Supervised Learning هستند، اما نوع خروجی متفاوت است.

نوعخروجیمثال

Regressionیک مقدار عددی پیوستهقیمت خانه، دما

ترفند ذهنی برای تمایز این دو:

  • Classification → What category?
  • Regression → How much?

4. Overfitting چیست؟

Overfitting زمانی رخ می‌دهد که مدل Training Data را بیش از حد به‌صورت اختصاصی یاد می‌گیرد و در نتیجه در داده‌های جدید عملکرد ضعیفی دارد.

Training Accuracy   = 99%
Validation Accuracy = 72%

در این حالت مدل روی داده‌های آموزشی بسیار خوب عمل می‌کند، اما قدرت Generalization ندارد.

Underfitting

در Underfitting مدل حتی روی Training Data هم عملکرد خوبی ندارد؛ یعنی مدل یا بیش از حد ساده است، یا آموزش کافی ندیده است.

راه‌های کاهش Overfitting

  • Data Augmentation
  • Regularization
  • Dropout
  • Early Stopping
  • افزایش حجم Dataset
  • کاهش پیچیدگی مدل
  • استفاده مناسب از Transfer Learning
تعریف به زبان انگلیسی: Overfitting happens when a model learns the training data too specifically and fails to generalize to unseen data.

5. Train / Validation / Test

بخشکاربرد
Training Setیادگیری پارامترهای مدل
Validation Setانتخاب مدل و تنظیم Hyperparameterها
Test Setارزیابی نهایی روی داده‌هایی که در فرآیند توسعه استفاده نشده‌اند
Dataset
├── Training   → Learn
├── Validation → Tune / Select
└── Test       → Final Evaluation

یک تقسیم‌بندی نمونه می‌تواند 70٪ Training، 15٪ Validation و 15٪ Test باشد؛ اما نسبت مناسب به Dataset و مسئله بستگی دارد.

نکته مهم:

Test Set نباید در انتخاب مدل یا تنظیم Hyperparameterها دخالت داشته باشد، چون در غیر این صورت ارزیابی نهایی دیگر کاملاً مستقل نخواهد بود.

6. چرا CNN برای داده‌های تصویری مناسب است؟

CNN (Convolutional Neural Network) برای داده‌های تصویری مناسب است، چون می‌تواند الگوهای محلی و ساختار فضایی تصویر را با استفاده از Convolution Filters استخراج کند.

Pixels
  ↓
Edges / Lines
  ↓
Textures / Shapes
  ↓
Complex Features
  ↓
Classification

در لایه‌های ابتدایی معمولاً ویژگی‌های ساده‌تری مانند Edge و Line استخراج می‌شوند و در لایه‌های عمیق‌تر، ویژگی‌های پیچیده‌تر شکل می‌گیرند.

دو مزیت اصلی CNN عبارت‌اند از:

  • Local Connectivity: فیلتر روی نواحی محلی تصویر کار می‌کند.
  • Weight Sharing: یک فیلتر در نقاط مختلف تصویر استفاده می‌شود و در نتیجه تعداد پارامترها نسبت به یک شبکه Fully Connected کاهش می‌یابد.
تعریف به زبان انگلیسی: CNNs are well suited for images because they preserve spatial structure and use convolution filters to learn local patterns such as edges, textures, and shapes.

7. خانواده EfficientNet و ایده Compound Scaling

EfficientNet خانواده‌ای از CNNهاست که روی ایجاد تعادل بین Accuracy، Model Size و Computational Cost تمرکز دارد.

Compound Scaling

ایده اصلی EfficientNet این است که به‌جای بزرگ کردن فقط یک بخش از شبکه، چند بُعد اصلی مدل به‌صورت متوازن افزایش داده شوند:

Compound Scaling
├── Depth       → تعداد / عمق لایه‌ها
├── Width       → تعداد کانال‌ها
└── Resolution  → وضوح ورودی تصویر

این رویکرد باعث می‌شود منابع محاسباتی به شکل متوازن‌تری بین عمق، عرض و Resolution مدل توزیع شوند.

انتخاب نسخه مناسب در خانواده EfficientNet

خانواده EfficientNet از B0 تا B7 نسخه‌های مختلفی دارد که هرچه شماره بالاتر برود، مدل بزرگ‌تر و دقیق‌تر ولی پرهزینه‌تر از نظر محاسباتی می‌شود. نسخه B3 نقطه‌ای میانی و عملی در این طیف است که معمولاً تعادل مناسبی بین دقت و هزینه محاسباتی ایجاد می‌کند و در بسیاری از مسائل Classification به‌عنوان یک Trade-off منطقی انتخاب می‌شود.

نکته روش‌شناسی:

بدون انجام Benchmark دقیق بین نسخه‌های مختلف (B0 تا B7) روی یک Dataset مشخص، نمی‌توان ادعا کرد که یک نسخه خاص به‌صورت مطلق «بهترین» است. صحیح‌تر آن است که انتخاب یک نسخه را بر اساس Trade-off میان دقت و هزینه محاسباتی توجیه کرد.

تعریف به زبان انگلیسی: EfficientNet-B3 offers a practical balance between classification performance and computational cost. EfficientNet uses compound scaling to scale depth, width, and input resolution in a more balanced way.

8. Transfer Learning چیست؟

در Transfer Learning از دانش یک مدل که قبلاً روی یک Dataset بزرگ آموزش دیده، برای یک مسئله جدید استفاده می‌شود.

Large Dataset
     ↓
Pretrained Model
     ↓
Learned Features
     ↓
New Dataset / Task
     ↓
Fine-tuning

برای مثال، EfficientNetی که روی یک Dataset بزرگ آموزش دیده، پیش از این ویژگی‌هایی مانند Edge، Texture و Shape را یاد گرفته است. به‌جای آموزش CNN از صفر، می‌توان از این دانش استفاده کرد و مدل را برای یک مسئله جدید Classification، مانند تشخیص سبک نقاشی، تطبیق داد.

مزایا

  • نیاز کمتر به Dataset بزرگ
  • کاهش زمان Training
  • کاهش هزینه محاسباتی
  • شروع از Featureهای از قبل یادگرفته‌شده
تعریف به زبان انگلیسی: Transfer learning means reusing knowledge learned by a pretrained model on a large dataset and adapting it to a new task, usually through feature reuse and fine-tuning.

9. Data Augmentation چه کاری انجام می‌دهد؟

Data Augmentation از داده‌های موجود، نمونه‌های متنوع‌تری تولید می‌کند تا مدل نسبت به تغییرات طبیعی داده مقاوم‌تر شود و Generalization بهتری داشته باشد.

Original Image
     ↓
 ┌───────────────┐
 │ Rotation      │
 │ Crop          │
 │ Flip          │
 │ Resize        │
 │ Color Change  │
 └───────────────┘
     ↓
More Diverse Training Samples

برای مثال، اگر تصویر یک نقاشی کمی چرخیده باشد، هدف این است که مدل به‌خاطر تغییر جزئی در زاویه یا Crop دچار خطا نشود.

نکته: Data Augmentation لزوماً به معنی جمع‌آوری داده واقعی جدید نیست؛ بلکه از داده موجود، نمونه‌های تغییر‌یافته تولید می‌کند.

تعریف به زبان انگلیسی: Data augmentation creates diverse variations of training samples, helping the model generalize better and reducing the risk of overfitting.

10. آیا Accuracy به‌تنهایی معیار کافی است؟

خیر، همیشه کافی نیست. Accuracy فقط نسبت پیش‌بینی‌های درست به کل پیش‌بینی‌هاست:

Accuracy = Correct Predictions / Total Predictions

مشکل اصلی زمانی مشخص می‌شود که Dataset نامتوازن باشد. برای مثال:

95% → Cat
 5% → Dog

اگر مدل همیشه Cat پیش‌بینی کند، Accuracy آن 95٪ خواهد بود؛ در حالی‌که عملاً چیزی درباره کلاس Dog یاد نگرفته است.

Precision

از بین مواردی که مدل Positive اعلام کرده، چند مورد واقعاً Positive بوده‌اند؟

Precision = TP / (TP + FP)

Recall

از تمام Positiveهای واقعی، مدل چند مورد را به‌درستی پیدا کرده است؟

Recall = TP / (TP + FN)

F1-Score

ترکیبی هارمونیک از Precision و Recall است:

F1 = 2 × (Precision × Recall) / (Precision + Recall)

بنابراین بسته به ماهیت مسئله، معمولاً لازم است علاوه بر Accuracy، معیارهایی مانند Precision، Recall، F1 و Confusion Matrix نیز بررسی شوند.

تعریف به زبان انگلیسی: Accuracy is not always sufficient, especially for imbalanced datasets. Depending on the problem, additional metrics such as precision, recall, F1-score, and the confusion matrix should also be evaluated.
