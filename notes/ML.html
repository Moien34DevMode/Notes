موضوع: مبانی Machine Learning و Deep Learning

هدف این جزوه ارائه یک دید مفهومی و منسجم از مبانی یادگیری ماشین و یادگیری عمیق است. مفاهیم به‌گونه‌ای ارائه شده‌اند که ارتباط میان الگوریتم‌ها، داده، آموزش مدل و ارزیابی عملکرد به‌صورت مرحله‌به‌مرحله قابل درک باشد.

1. Machine Learning چیست؟

Machine Learning شاخه‌ای از هوش مصنوعی است که در آن به‌جای تعریف دستی تمام قوانین تصمیم‌گیری، به مدل داده می‌دهیم تا الگوهای موجود در داده را یاد بگیرد و سپس برای داده‌های جدید پیش‌بینی یا تصمیم‌گیری کند.

Data → Learning Algorithm → Model → Prediction

مثلاً در تشخیص سبک نقاشی، به‌جای نوشتن قوانین دستی برای تشخیص Van Gogh یا Picasso، تصاویر برچسب‌دار را به مدل می‌دهیم تا ویژگی‌های مرتبط با سبک را یاد بگیرد.

نکته مفهومی: در یادگیری ماشین، هدف اصلی یادگیری رابطه یا الگوی موجود در داده‌هاست؛ به‌طوری که مدل بتواند پس از آموزش، روی نمونه‌هایی که قبلاً مشاهده نکرده است نیز عملکرد مناسبی داشته باشد.

2. Supervised و Unsupervised Learning چه تفاوتی دارند؟

Supervised Learning

داده‌ها دارای Label هستند و مدل یاد می‌گیرد ورودی را به خروجی مورد انتظار مرتبط کند.

Image → Label
Painting → Van Gogh
Painting → Picasso
```

Unsupervised Learning

داده‌ها Label ندارند و مدل تلاش می‌کند ساختار یا الگوهای موجود در داده را خودش پیدا کند؛ مانند Clustering.

Unlabeled Data → Model → Discovered Groups / Patterns

نکته کاربردی:

پروژه PaintingStyleRecognition یک مسئله Supervised Learning است، چون تصاویر دارای Label هستند.

```
نکته مفهومی: در Supervised Learning، وجود نمونه‌های برچسب‌دار امکان یادگیری رابطه میان ورودی و خروجی را فراهم می‌کند؛ در حالی که در Unsupervised Learning، الگوریتم بدون دریافت خروجی صحیح، ساختارهای درونی داده را بررسی می‌کند.

3. Classification و Regression

هر دو معمولاً از مسائل Supervised Learning هستند، اما نوع خروجی متفاوت است.

نوعخروجیمثال
Classificationیک کلاس یا دستهCat / Dog، Van Gogh / Picasso
Regressionیک مقدار عددی پیوستهقیمت خانه، دما

تفاوت اصلی:

  • Classification → What category?
  • Regression → How much?

4. Overfitting چیست؟

Overfitting زمانی رخ می‌دهد که مدل Training Data را بیش از حد به‌صورت اختصاصی یاد می‌گیرد و در داده‌های جدید عملکرد ضعیفی دارد.

Training Accuracy   = 99%
Validation Accuracy = 72%

مدل در Training بسیار خوب است، اما قدرت Generalization ندارد.

```

Underfitting

در Underfitting مدل حتی روی Training Data هم عملکرد خوبی ندارد؛ یعنی مدل یا بیش از حد ساده است، یا آموزش کافی ندیده است.

راه‌های کاهش Overfitting

  • Data Augmentation
  • Regularization
  • Dropout
  • Early Stopping
  • افزایش Dataset
  • کاهش پیچیدگی مدل
  • استفاده مناسب از Transfer Learning
```
نکته مفهومی: Overfitting نشان‌دهنده ضعف در Generalization است. بنابراین هنگام آموزش مدل باید علاوه بر عملکرد روی داده‌های آموزشی، عملکرد آن روی داده‌های مستقل مانند Validation و Test نیز بررسی شود.

5. Train / Validation / Test

بخشکاربرد
Training Setیادگیری پارامترهای مدل
Validation Setانتخاب مدل و تنظیم Hyperparameterها
Test Setارزیابی نهایی روی داده‌هایی که در فرآیند توسعه استفاده نشده‌اند
``` 
Dataset
```

├── Training   → Learn
├── Validation → Tune / Select
└── Test       → Final Evaluation
```

یک تقسیم‌بندی نمونه می‌تواند 70٪ Training، 15٪ Validation و 15٪ Test باشد؛ اما نسبت مناسب به Dataset و مسئله بستگی دارد.

نکته مهم:

Test Set نباید در انتخاب مدل یا تنظیم Hyperparameterها دخالت داشته باشد، چون در غیر این صورت ارزیابی نهایی دیگر کاملاً مستقل نیست.

```

6. چرا CNN برای Image مناسب است؟

CNN (Convolutional Neural Network) برای داده‌های تصویری مناسب است چون می‌تواند الگوهای محلی و ساختار فضایی تصویر را با استفاده از Convolution Filters استخراج کند.

``` 
Pixels
```

↓
Edges / Lines
↓
Textures / Shapes
↓
Complex Features
↓
Classification
```

در لایه‌های ابتدایی معمولاً ویژگی‌های ساده‌تر مانند Edge و Line استخراج می‌شوند و در لایه‌های عمیق‌تر ویژگی‌های پیچیده‌تر شکل می‌گیرند.

دو مزیت مهم CNN:

  • Local Connectivity: فیلتر روی نواحی محلی تصویر کار می‌کند.
  • Weight Sharing: یک فیلتر در نقاط مختلف تصویر استفاده می‌شود و تعداد پارامترها را نسبت به یک شبکه Fully Connected بزرگ کاهش می‌دهد.
```
نکته مفهومی: CNN با استفاده از عملیات Convolution ساختار فضایی تصویر را حفظ کرده و ویژگی‌های محلی را استخراج می‌کند. این ویژگی‌ها می‌توانند از الگوهای ساده مانند لبه‌ها شروع شده و در لایه‌های عمیق‌تر به الگوهای پیچیده‌تر تبدیل شوند.

7. چرا EfficientNet-B3 را انتخاب کردی؟

EfficientNet خانواده‌ای از CNNهاست که روی ایجاد تعادل بین Accuracy، Model Size و Computational Cost تمرکز دارد.

```

Compound Scaling

ایده مهم EfficientNet این است که به‌جای بزرگ کردن فقط یک بخش از شبکه، چند بُعد اصلی مدل را به‌صورت متوازن افزایش دهیم:

Compound Scaling
```

├── Depth       → تعداد / عمق لایه‌ها
├── Width       → تعداد کانال‌ها
└── Resolution  → وضوح ورودی تصویر
```

این کار باعث می‌شود منابع محاسباتی به شکل متوازن‌تری بین عمق، عرض و Resolution مدل استفاده شوند.

موقعیت B3 در خانواده EfficientNet

B3 یک نقطه میانی و عملی در خانواده EfficientNet است که می‌تواند تعادل مناسبی بین دقت و هزینه محاسباتی ایجاد کند. برای پروژه Classification، انتخاب آن می‌تواند یک Trade-off عملی بین Performance و Resource Usage باشد.

نکته آموزشی:

انتخاب یک معماری شبکه عصبی باید بر اساس ویژگی‌های مسئله، اندازه Dataset، منابع محاسباتی، زمان آموزش و معیارهای ارزیابی انجام شود. بنابراین انتخاب B3 لزوماً به معنای برتری آن نسبت به تمام مدل‌های دیگر نیست.

```
نکته مفهومی: EfficientNet با استفاده از Compound Scaling تلاش می‌کند Depth، Width و Input Resolution را به‌صورت متوازن افزایش دهد. EfficientNet-B3 یکی از مدل‌های این خانواده است که می‌تواند میان دقت و هزینه محاسباتی تعادل مناسبی ایجاد کند.

``` 
Large Dataset
 ↓
```

Pretrained Model
↓
Learned Features
↓
New Dataset / Task
↓
Fine-tuning
```

مثلاً EfficientNet که روی یک Dataset بزرگ آموزش دیده، قبلاً ویژگی‌هایی مانند Edge، Texture و Shape را یاد گرفته است. به‌جای آموزش CNN از صفر، می‌توانیم از این دانش استفاده کنیم و مدل را برای Painting Style Classification تطبیق دهیم.

مزایا

  • نیاز کمتر به Dataset بزرگ
  • کاهش زمان Training
  • کاهش هزینه محاسباتی
  • شروع از Featureهای از قبل یادگرفته‌شده
```
نکته مفهومی: Transfer Learning به معنای استفاده مجدد از دانش یک مدل ازپیش‌آموزش‌دیده برای یک مسئله جدید است. این روش به‌ویژه زمانی اهمیت دارد که Dataset جدید نسبتاً کوچک باشد یا آموزش کامل یک مدل از ابتدا هزینه محاسباتی زیادی داشته باشد.

9. Data Augmentation چه کاری می‌کند؟

Data Augmentation از داده‌های موجود، نمونه‌های متنوع‌تری ایجاد می‌کند تا مدل نسبت به تغییرات طبیعی داده مقاوم‌تر شود و Generalization بهتری داشته باشد.

``` 
Original Image
 ↓
```

┌───────────────┐
│ Rotation      │
│ Crop          │
│ Flip          │
│ Resize        │
│ Color Change  │
└───────────────┘
↓
More Diverse Training Samples
```

مثلاً اگر تصویر یک نقاشی کمی چرخیده باشد، هدف این است که مدل به‌خاطر تغییر جزئی در زاویه یا Crop دچار خطا نشود.

نکته: Data Augmentation لزوماً به معنی جمع‌آوری داده واقعی جدید نیست؛ بلکه از داده موجود، نمونه‌های تغییر‌یافته تولید می‌کند.

```
نکته مفهومی: Data Augmentation با ایجاد تغییرات کنترل‌شده در نمونه‌های آموزشی، تنوع داده را افزایش می‌دهد. انتخاب نوع Augmentation باید با ماهیت مسئله سازگار باشد؛ زیرا بعضی تغییرات ممکن است معنای اصلی داده یا Label آن را تغییر دهند.

10. Accuracy کافی است؟

نه، همیشه. Accuracy فقط نسبت پیش‌بینی‌های درست به کل پیش‌بینی‌هاست:

```
Accuracy = Correct Predictions / Total Predictions

مشکل زمانی مشخص می‌شود که Dataset نامتوازن باشد.

مثلاً:

95% → Cat
```

5% → Dog
```

اگر مدل همیشه Cat بگوید، Accuracy آن 95٪ می‌شود؛ اما برای Dog عملاً هیچ چیزی یاد نگرفته است.

Precision

از بین مواردی که مدل Positive اعلام کرده، چند مورد واقعاً Positive بوده‌اند؟

Precision = TP / (TP + FP)

Recall

از تمام Positiveهای واقعی، مدل چند مورد را پیدا کرده است؟

Recall = TP / (TP + FN)

F1-Score

ترکیبی از Precision و Recall است:

F1 = 2 × (Precision × Recall) / (Precision + Recall)

بنابراین بسته به مسئله ممکن است علاوه بر Accuracy به Precision، Recall، F1، Confusion Matrix و حتی معیارهای دیگر نیاز داشته باشیم.

```
نکته مفهومی: انتخاب معیار ارزیابی باید متناسب با ماهیت مسئله و توزیع کلاس‌ها انجام شود. در Datasetهای نامتوازن، Accuracy ممکن است تصویر دقیقی از عملکرد مدل ارائه نکند و استفاده از Precision، Recall، F1-Score و Confusion Matrix اطلاعات کامل‌تری فراهم می‌کند.
